Columns, built in the open.

Each OpenBasalt project lives in its own repository, with its own purpose and release cycle. All of them are young: they work in the source today, and none has a stable release yet.

Projects

Samba Conductor

Pre-release

A Samba Active Directory domain run from a web console, with single sign-on through OpenID Connect and SAML, Google Workspace sync, a self-service portal, encrypted backups and file servers. Packages for Debian, Ubuntu, Fedora and Basalt OS.

Project page Source

Basalt OS

Pre-alpha

A Linux distribution based on Fedora, built security and AI first: AI agents can do real work on the system through typed, auditable actions, always confined and confirmed by a person. Not installable as a release yet.

basalt-os.org Source

obpkg.org

Live

The download domain for OpenBasalt packages, all signed with the OpenBasalt release key: basalt for Basalt OS, basalt-tools for our tools on Fedora-based systems, basalt-testing for packages on their way, opt-in, and an APT repository for Samba Conductor.
